# Boost Poker

Быстрый 6-max No-Limit Hold'em для игры с друзьями в браузере — как PokerNow, но в формате **Boost / Zoom**:
нажали «Фолд» — и сразу оказались за новым столом с новыми картами.

- Общий пул игроков, сервер собирает из него столы до 6 человек (при 7–12 игроках обычно 1–2 стола параллельно).
- **Быстрый фолд** — можно сбросить карты ещё до своей очереди; остальные увидят фолд, только когда дойдёт ход.
- Полноценные правила NLHE: сайд-поты, олл-ины с докладкой борда, неполный рейз не открывает торговлю, хедз-ап порядок.
- Учёт стеков: закупы, докупки, итог «+/−» по каждому игроку, кнопка «Скопировать итоги» для расчёта.
- Хост: блайнды, лимит стека, время на ход, пауза, добавить/снять фишки, удалить игрока, передать хоста.
- Таймер хода (вышло время — авточек или фолд и пропуск раздач), чат, лог стола, история своих раздач, звук хода,
  горячие клавиши **F** — фолд, **C** — чек/колл, **R** — рейз, **Пробел** — дальше.
- Работает на телефоне. Нет внешних зависимостей — только Node.js 18+.

## Запуск у себя

```bash
node server.js          # http://localhost:3000
```

Чтобы друзья подключились к вашему компьютеру, можно открыть туннель: `npx cloudflared tunnel --url http://localhost:3000`
(или `ngrok http 3000`) и разослать выданную ссылку.

## Бесплатный хостинг на Render (рекомендуется)

1. Зарегистрируйтесь на [github.com](https://github.com), создайте новый репозиторий (**New repository**, можно приватный).
   На странице репозитория нажмите **Add file → Upload files** и перетащите **содержимое** этой папки
   (`server.js`, `package.json`, `render.yaml`, папки `lib`, `public`, `test`). Нажмите **Commit changes**.
2. Зарегистрируйтесь на [render.com](https://render.com) через GitHub.
3. **New → Web Service** → выберите репозиторий.
   - Runtime: **Node**
   - Build Command: `npm install`
   - Start Command: `node server.js`
   - Instance Type: **Free**
4. Через 1–2 минуты появится адрес вида `https://boost-poker-xxxx.onrender.com`. Откройте его, создайте игру,
   нажмите **«Пригласить»** — ссылка скопируется, отправьте её друзьям.

### Важно про бесплатный тариф
- Если сайт никто не открывал ~15 минут, Render его «усыпляет». Первое открытие после сна занимает до минуты.
  Пока страница игры открыта хотя бы у одного игрока, сайт сам себя будит.
- Игры хранятся в памяти сервера. При перезапуске (сон, обновление кода) **игры и итоги обнуляются** —
  перед тем как расходиться, нажмите «Итоги → Скопировать итоги».

## Как устроен Boost-пул

- Все, кто не пропускает раздачи, стоят в очереди. Как только в очереди 6 человек — сразу садится стол.
- Если других столов нет — стол садится с теми, кто есть (от 2 человек).
- Если кто-то ещё доигрывает, сервер ждёт полный стол до `waitSec` секунд (по умолчанию 5), а потом сажает
  неполный стол от `minTable` игроков (по умолчанию 4). Оба параметра хост меняет в настройках.
- Большой блайнд получает тот, кто дольше всех его не платил, — блайнды распределяются честно.
- Стек переезжает с вами между столами целиком. Докупка — до «макс. стека» (если вы в раздаче, фишки добавятся к следующей).
- Если вы сфолдили быстрым фолдом с большого блайнда, а все сбросили до вас — банк ваш, он зачислится автоматически.

## Тесты

```bash
npm test                                   # движок (20 000 случайных раздач) + симуляция пула из 9 ботов
node test/bots.js http://localhost:3000 new 7 60   # боты играют по WebSocket — удобно, чтобы потестить одному
```
`bots.js` печатает ID игры — откройте `http://localhost:3000/g/<ID>` и садитесь к ботам.
